# Contributing

## Branches

- Create feature branches from `dev`.
- Merge feature branches into `dev`.
- Merge `dev` into `main` only when a release checkpoint is ready.
- Create release tags from `main`.

## Commit Messages

Use Conventional Commits:

```text
type(scope): description
```

Examples:

```text
feat(items): add item create form
fix(categories): keep items when category is deleted
docs(roadmap): update v1 release plan
ci(github): add verification workflow
```
